# Ben Krack - Senior Software Engineer – Test & Infrastructure Leader Portfolio

A modern, high-performance portfolio showcase website for **Ben Krack** (Senior Software Engineer – Test & Infrastructure Leader), built with React, Vite, TypeScript, Tailwind CSS, and shadcn/ui.

## Features
- **Overview Splash Page (`/`)**: Executive engineering summary, career impact metrics ($30B risk mitigated, 73% defect reduction, 32+ products tested), core test engineering disciplines, and interactive keyword cross-reference.
- **Company Deep Dives (`/portfolio` or `/companies`)**: Comprehensive system architecture breakdowns for **Addepar**, **LinkedIn**, **Google**, and **Slalom Consulting**, including custom vector logos, quantifiable outcomes, and alignment with senior test engineering roles.
- **Prominent Community Leadership**: Highlighted 501(c)(3) nonprofit board governance and volunteer initiatives.
- **Academic Foundation**: University of Washington (BS in Computer Science & Engineering, BA in Business Administration).

## Getting Started

### Prerequisites
- Node.js 18+ & npm

### Development
```bash
npm install
npm run dev
```
The local server runs by default at `http://localhost:8080`.

### Production Build
```bash
npm run build
npm run preview
```
